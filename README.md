### Структура проекта

- **/diagrams**: содержит диаграммы из Задания 1 (1.1; 1.2; 1.3) и 5,6.
- **/mongo-sharding**: содержит Задание 2
- **/mongo-sharding-repl**: содержит Задание 3
- **/sharding-repl-cache**: содержит Задание 4
- **/old-version**: содержит старую версию проекта (без шардирования монги, кэширования и репликации)

В **каждой** директории есть файл **README.md**, в котором описано, как запустить конкретный проект и проверить его (*есть init/test в папке scripts скрипты для Заданий 2-4*)
